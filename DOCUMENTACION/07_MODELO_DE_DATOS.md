# 07. Modelo de datos

**Estado:** PENDIENTE DE DEFINICIÓN

No hay datos de dominio, archivos de ejemplo, esquemas, entidades ni diccionario de datos en el repositorio. No se inventan tablas, campos, claves o relaciones.

## Información requerida

- Fuente y formato de cada conjunto de datos.
- Definición, tipo, unidad, nulabilidad y dominio válido de cada campo.
- Identificador y granularidad de cada registro.
- Relaciones, temporalidad y reglas de calidad.
- Clasificación de sensibilidad, retención y trazabilidad necesarias.

Cuando el usuario comparta un ejemplo anonimizado y sus definiciones, se documentará un modelo conceptual y lógico y se confirmarán con el responsable del proceso antes de elegir almacenamiento o implementar transformaciones.
